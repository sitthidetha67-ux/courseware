# AR Courseware - วิทยาการคำนวณ ม.5
ระบบคอร์สแวร์บทเรียนคอมพิวเตอร์ช่วยสอน (CAI) เรื่อง "เทคโนโลยีความจริงเสริมเพื่อการศึกษา" สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 5 รายวิชาวิทยาการคำนวณ โรงเรียนนวัตกรรมวิทยา

## คุณสมบัติเด่น (Features)
- **สถาปัตยกรรมไร้เซิร์ฟเวอร์ (Serverless):** หน้าเว็บ HTML แบบไฟล์เดียว (SPA) ทำงานร่วมกับ Supabase Backend
- **การจัดการผู้ใช้:** ผูกบัญชีนักเรียนอัตโนมัติผ่าน Database Trigger โดยใช้รหัสประจำตัวนักเรียน 5 หลัก
- **ระบบความปลอดภัย (RLS):** นักเรียนเข้าถึงได้เฉพาะข้อมูลของตนเอง ป้องกันการแก้ไขคะแนนด้วย Trigger
- **ระบบสอบ:** สุ่มข้อสอบชุด A และ B (คู่ขนาน) ตามเลขรหัสคู่/คี่ พร้อมคำนวณค่า Normalized Gain (Hake)
- **การจัดการสื่อและชิ้นงาน:** ระบบอัปโหลดไฟล์ (Storage) แยกตามสิทธิ์การเข้าถึง พร้อม Signed URLs

## โครงสร้างไฟล์
- `courseware.html`: หน้าเว็บหลัก รวม UI (Tailwind CSS), ระบบ (JavaScript), เนื้อหาบทเรียน และข้อสอบ
- `setup.sql`: สคริปต์ SQL สำหรับสร้างตาราง, นโยบายความปลอดภัย (RLS), Triggers และข้อมูลจำลอง
- `README.md`: ไฟล์เอกสารนี้

## การติดตั้ง (Deployment)
กรุณาอ่านคำแนะนำในส่วน "คู่มือติดตั้ง" ในเอกสารหลักเพื่อตั้งค่า Supabase และกำหนดค่า API Key ก่อนใช้งาน
นักเรียนจะใช้อีเมลรูปแบบ `[รหัส5หลัก]@nws.ac.th` ในการสมัครและเข้าใช้งาน
